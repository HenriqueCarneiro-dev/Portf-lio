# Portfólio

Uma apresentação pessoal com projetos, habilidades e contato — feita com HTML, CSS e JavaScript.

## Visão geral
Este repositório contém o meu portfólolio (site estático) que reúne projetos, informações profissionais e formas de contato. O objetivo é mostrar minhas habilidades em desenvolvimento web e servir como ponto de contato para oportunidades.

## Tecnologias
- HTML
- CSS (Flexbox / Grid)
- JavaScript (vanilla)
- (Opcional) ferramentas de build simples se usadas: npm, parcel, etc.

## Funcionalidades
- Página inicial com apresentação
- Seção de projetos com links e descrições
- Seção de habilidades / tecnologias
- Formulário de contato (pode enviar via email ou integração)
- Layout responsivo para dispositivos móveis
